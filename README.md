# RUDRA-TECH

A central workspace for the RUDRA digital projects, using a premium dark AI-dashboard visual system with responsive navigation, glass panels, gradient accents, and lightweight motion.

## Projects
- **Hackwithrudra** — technology learning and cybersecurity education.
- **Working with Rudra** — work, services, and productivity.
- **Baby With Ved** — original children's songs, stories, and videos.
- **Freelance** — portfolio and freelance service resources.
- **Social Media** — content planning and social media management.
- **RUDRA AI HUB** — Gemini-powered assistant with specialist agents for research, content, creative, media, building, and review.

## Design system
- Shared responsive dark navy dashboard theme across the project hub and all five project pages.
- Mobile-first navigation, glass-effect cards, blue/cyan/violet lighting, animated hero orb, and reduced-motion support.
- Brand accent variations for Baby With Ved, Hack With Rudra, Working With Rudra, Freelance, and Social Media.
- Central workflow section with Plan → Build → Test → Launch stages and a six-project milestone board.
- Interactive project task board: create tasks, assign a project, filter pending/completed, and delete tasks. Data stays in the current browser's local storage; it is not synced between devices.
- Expanded Hack With Rudra learning paths, Working With Rudra service catalogue, Freelance service menu, and Social Media weekly content plan.
- Baby With Ved Episode 002 has its own original lyrics draft and seven-scene storyboard.

## Status
The RUDRA-TECH Pages deployment is automated through GitHub Actions. The most recent code changes are being deployed and must pass the latest workflow run before they are considered live.
RUDRA AI HUB has a live Vercel production deployment. Gemini chat and initial research/code-generation responses have been manually tested; specialist-agent routing and remaining agent behaviors are still being verified.
