LEARNING PATHS

Build skills step by step

PATH 01

IT Support Fundamentals

Windows troubleshooting, user accounts, device setup, backups, printers, and Microsoft 365 basics.

Practice: Diagnose a slow PC, document symptoms, test a fix, and write a clear resolution.

PATH 02

Networking Essentials

IP addressing, subnet basics, DHCP, DNS, Wi-Fi, VPN concepts, and connectivity troubleshooting.

Practice: Follow an IP → gateway → DNS checklist and record the result.

PATH 03

Windows Administration

Active Directory concepts, permissions, Group Policy, patching, logs, and backup planning.

Practice: Create a safe lab checklist for a new workstation.

PATH 04

Cybersecurity Basics

Threat awareness, MFA, password hygiene, updates, least privilege, and incident reporting.

Practice: Review a sample phishing email without opening attachments or links.

SAFE PRACTICE LAB

Learn in systems you own or are authorized to test.

Use virtual machines, intentionally vulnerable training labs, and your own devices. Do not scan, access, or test systems without explicit permission.

Lab report template
Objective → Authorized scope → Environment → Steps performed → Evidence → Findings → Fix → Retest result.

QUICK CHECKLIST

Network troubleshooting order

1 · Link

Check Wi-Fi/Ethernet connection and airplane mode.

2 · IP

Check IP address, subnet, gateway, and DHCP lease.

3 · DNS

Test name resolution separately from raw connectivity.

4 · Route

Check gateway, VPN, proxy, and route path as authorized.
